# SauceDemo Manual Testing Portfolio

Manual testing of [SauceDemo](https://www.saucedemo.com), a demo e-commerce site, written and tracked in Jira.

**Tester:** Jaleel Meli | **Tested:** 25 Sep to 14 Oct 2026 | **Environment:** Safari on macOS

## What's in the portfolio
- Test plan (scope, approach, risks, entry and exit criteria)
- 8 test cases (positive and negative) covering login, sorting and product pages
- 5 defect reports, each with steps, severity, priority and evidence
- Exploratory testing session report (charter, time box, findings)
- Requirements traceability matrix (12 requirements)

## Results
8 test cases executed: 6 passed, 2 failed. 5 defects logged: 2 High, 1 Medium, 2 Low.
